ABOUT THE PROJECT

Synthetic faces, curated for exploration.

CompactFaces 1.0.0 is a curated synthetic-face collection organized by identity. The gallery gives people a way to inspect each set of five images without downloading the original files.

187identity families
935accepted images
1024pxoriginal PNG resolution

DATASET STRUCTURE

One identity, five views

There are 120 Core families (600 images) and 67 Additional Optional families (335 images). Each family has five named views:

SOURCE

Reference portrait for the synthetic identity.

P1

First pose variation.

P2

Second pose variation.

E1

First expression variation.

E2

Second expression variation.

The identity labels describe synthetic image groups; they do not establish biometric uniqueness or guarantee that faces cannot resemble real people.

TECHNICAL IMPLEMENTATION

How the source code works

01 / DATA

Image generation and edits

Images were generated and edited using Mage-Flow-Turbo and Mage-Flow-Edit-Turbo. Published prompt metadata alone does not enable byte-identical reproduction of all 935 images.

02 / VALIDATE

Integrity verification

Python validators check each identity’s five slots, the release inventory and SHA256 hashes of the 1024px PNG originals before generating preview assets.

03 / BUILD

Static gallery build

Python and Pillow produce WebP thumbnails at 400px and detail previews at 768px. Responsive HTML, CSS and vanilla JavaScript power the gallery without a backend or external UI framework.

04 / ACCESS

Separate original downloads

Original 1024px PNGs and metadata are hosted on Hugging Face and Kaggle. The engineering toolkit is on GitHub.

Dataset and source code

Access original images and metadata via Hugging Face or Kaggle, and explore the project tools on GitHub.

TRANSPARENCY AND REMOVAL

Images can be synthetic and still resemble someone.

If you believe a face resembles you or you have a rights or privacy concern, you can request review of a specific identity or image. Please provide the identity code and the view (if relevant); you do not need to upload a selfie through this site.

Model licenses and generated-dataset redistribution rights are separate questions. The viewer does not claim biometric uniqueness or grant redistribution rights over externally supplied image data.
