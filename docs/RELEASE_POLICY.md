# Distribution boundaries and licensing

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](RELEASE_POLICY.vi.md)

## Know which artifact you are using

| Artifact | Contents | Terms / responsibility |
|---|---|---|
| [GitHub pipeline](https://github.com/dangkhoa2016/CompactFaces-Synthetic-Face-Pipeline) | code, examples, documentation and notebook source | [MIT](../LICENSE) for owned code/docs |
| [Hugging Face dataset](https://huggingface.co/datasets/dangkhoa2016/compactfaces-synthetic-face-dataset) | original images and metadata | [CC BY-NC 4.0](../LICENSE-NOTES.md) for rights-controlled material |
| [Kaggle Dataset Version 1](https://www.kaggle.com/datasets/dangkhoa2016/compactfaces-synthetic-face-dataset) | dataset distribution and supplementary assets | dataset license, not GitHub MIT |
| [Gallery](https://compactfaces-synthetic-face-dataset.dangkhoa.dev/) | derived WebP previews | image distribution restrictions still apply |
| Upstream models | external weights and inference runtime | separate licenses and hosting terms |

This repository does **not** include original images, model weights, access tokens or complete candidate-selection records. Users may run standalone code examples without acquiring the full dataset.

## Before sharing results

1. Verify the files you have with [the validation tools](validation.md).
2. Read the dataset and upstream model licensing; source-code MIT is **not** an image or model-weight license.
3. Do not claim full pixel-identical regeneration, biometric uniqueness, or guaranteed non-resemblance to real people.
4. When publishing images or previews, ensure the rights for those particular assets are appropriate.
